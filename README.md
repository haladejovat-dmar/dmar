# D’MAR — ukázkový web pro GitHub Pages

Toto je statická demonstrační verze webu D’MAR se zabudovanými fotografiemi produktů a přepínáním CZ/EN.

## Nasazení
1. Na GitHubu vytvoř nový repozitář (doporučený název `dmar-web`).
2. Nahraj **obsah této složky** do kořene repozitáře: `index.html` a `.nojekyll` (README je nepovinný).
3. V repozitáři otevři Settings → Pages a v Build and deployment vyber Deploy from a branch → main → /(root). Ulož.
4. Stránky se poté objeví na adrese GitHub Pages repozitáře. Doménu `dmar.cz` připojuj až po ověření webu.

## Důležité
- **Nejde o Shopify motiv**: ZIP nelze importovat do Shopify mezi Themes.
- Košík a ceny jsou pouze ukázkové, nelze dokončit živou objednávku; před spuštěním prodeje je třeba nasadit Shopify obchod.
- Právní texty mohou obsahovat zástupné údaje a potřebují dokončení před spuštěním e-shopu.
- Při veřejném repozitáři může kdokoli vidět kód webu i vložené fotografie.
